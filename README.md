# CS Dashboard - FAQ Seller

Dashboard interaktif untuk menampilkan FAQ berdasarkan hirarki menu seller. Terintegrasi dengan Google Apps Script backend.

## Fitur

- ✅ Tree menu dinamis dari Google Sheet
- ✅ Tampilkan FAQ per menu
- ✅ Pencarian konten FAQ (pertanyaan & jawaban)
- ✅ Desain responsif (mobile friendly)
- ✅ Highlight kata kunci pencarian
- ✅ Toggle jawaban accordion
